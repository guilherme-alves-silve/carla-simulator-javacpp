## Boost C++ Libraries

The native bridge links against `boost_filesystem` on Linux
(Boost is header-only on most other subsystems since 1.66, so
only the filesystem component is linked as a separate binary).
On Windows the Boost dependency is satisfied by the
[Microsoft STL and the Windows SDK](https://github.com/microsoft/STL)
bundled with Visual Studio, so the bridge uses `Shlwapi`
instead (see below).

## Shlwapi

On Windows, the Boost.Filesystem implementation (shipped with
the Microsoft Visual C++ runtime) uses the
**Shell Lightweight Utility API** (`Shlwapi.lib`) to resolve
path and URL strings. `Shlwapi` is a proprietary component of
the Microsoft Windows SDK.

### License

`Shlwapi` is part of the operating system; consumers obtain it
through the Windows SDK or as part of a standard Windows
installation. No redistribution of the library is required by
this artifact. Linking against it dynamically from a
user-built `.dll` is permitted under the Windows SDK license
terms.
